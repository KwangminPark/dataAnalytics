기본 실습 1 · 브랜드별 n과 분포

날짜별 행 수와 브랜드별 행 수를 확인한 뒤 평균·중앙값·산포를 구합니다. 분석 질문은 세 브랜드 평균이 모두 같은가이며, 모든 쌍이 다르다는 가설을 처음부터 정답으로 두지 않습니다.

기본 실습 2 · ANOVA 표 읽기

sales~brand 모형의 자유도, 집단 간/집단 내 변동, F값, p값을 짚습니다. F는 집단 간 차이가 집단 안의 흔들림에 비해 얼마나 큰지 비교합니다. F가 크다고 다음 달 매출을 정확히 예측하는 것은 아닙니다.

기본 실습 3 · 어디가 다른지 확인

Tukey 표의 comparison은 뒤 집단을 앞 집단에서 뺀 방향으로 읽습니다. diff, lwr, upr, p adj를 함께 기록합니다. 여러 쌍을 비교하므로 보정된 구간과 p값을 사용합니다. p adj가 출력상 0처럼 보이면 매우 작은 값으로 표현합니다.

기본 실습 4 · 가정과 전달력 점검

잔차-적합값 그림과 Q-Q 그림을 읽고 Welch ANOVA도 비교합니다. Welch는 등분산 가정에 대한 대안이지 날짜별 의존성의 해결책은 아닙니다. 비전공자에게 세 문장으로 “관측 차이—남는 불확실성—다음 행동”을 설명하는 보고서를 만듭니다.

## 2. 모든 집단이 같은가? 전체 검정 다음에 쌍별 차이를 봅니다.

```{r}
#| label: analysis-2
# 2. 모든 집단이 같은가? 전체 검정 다음에 쌍별 차이를 봅니다.
m <- aov(sales~brand,data=d)
print(summary(m)); post <- TukeyHSD(m)$brand
export(data.frame(comparison=rownames(post),post,check.names=FALSE,row.names=NULL),"tukey")
# 분포와 잔차. 좋은 그림은 관측의 독립성을 증명하지 않습니다.
picture("anova-check",1200,800); par(mfrow=c(2,2))
boxplot(sales~brand,d,ylab="Daily sales (KRW)",names=c("Mega","Starbucks","Compose"))
plot(fitted(m),resid(m),xlab="Fitted sales",ylab="Residual"); abline(h=0,lty=2)
qqnorm(resid(m)); qqline(resid(m))
plot(TukeyHSD(m),las=1,cex.axis=0.7)
dev.off()
cat("Residual normality diagnostic:
"); print(shapiro.test(resid(m)))
cat("Welch ANOVA sensitivity:
"); print(oneway.test(sales~brand,data=d,var.equal=FALSE))
```

제출할 분석 기록

ANOVA 전체 질문, Tukey에서 고른 두 비교, 분포/잔차 그림, 3문장 경영 요약을 제출합니다. 같은 자료의 관측 의존성을 어떻게 추가 확인할지도 한 문장으로 적습니다. 질문→자료→방법→근거→실행/보류 판단을 연결합니다. 공식 제출은 집현캠퍼스 안내를 따릅니다. 마감일·배점은 이 자료에서 정하지 않습니다. 스스로 확인: ANOVA가 유의하다는 것과 모든 쌍의 차이를 구별했는가? 90행을 90개 매장이라고 하지 않았는가?
