# 7장 LAB · 광고는 누구에게, 어떤 경로로 연결될까?

연령에 따라 광고와 구매의 관계가 달라진다는 말과 광고가 태도를 거쳐 구매와 연결된다는 말은 다릅니다. “누구에게/언제”와 “어떤 경로로”라는 두 질문을 먼저 분리합니다.

## 교재와 연결

[조절효과와 매개효과](https://kwangminpark.github.io/businessAnalytics/Chapter7.html) — 7.2 연령 조절, 7.3 태도 매개, 7.4.6 조절된 매개

선수학습: 6장: 회귀계수·상호작용·통제변수

권장 시간: 기본 110분 + 심화 35분 (수업 운영에 따라 조절)

## 이번 실습에서 배울 것

- 조절변수와 매개변수를 그림과 말로 구별한다.
- 중심화된 조절모형에서 조건부 기울기를 구한다.
- 간접효과 a×b와 그 불확실성, 인과 해석의 조건을 설명한다.

## 먼저 읽을 데이터

moderation.csv, mediation.csv, moderated-mediation.csv는 교재 7.2·7.3·7.4의 공개 생성식을 R 기본 대입문으로 옮겨 재현한 각각 300행의 가상자료입니다. 시드는 42, 123, 1입니다. ad_exposure는 노출 횟수, age는 연령, attitude는 가상의 연속 태도 점수, purchase_amount는 생성식의 가상 구매 단위입니다. 태도를 1~5 점수로, 구매 단위를 원으로 바꾸어 부르지 않습니다. 세 파일은 서로 다른 예제이며 행끼리 이어 붙이지 않습니다.

## 준비와 실행

전체 ZIP을 새 폴더에 풀고 report-template.qmd를 엽니다. 문서 안의 번호별 R 청크를 순서대로 실행합니다. 분석 코드와 판단·해석 작성란은 QMD에서 수정합니다. `quarto render report-template.qmd --to html`로 보고서를 생성합니다. 원본 data를 덮어쓰지 않고 계산 결과는 output에 저장됩니다.

## Quarto 학생 분석 보고서

학생용 report-template.qmd와 교수자 예시 reference-report.qmd는 제공된 Quarto 학생 리포트 템플릿을 기반으로 합니다. 첫 페이지는 결론·권고·핵심 근거·실무적 의미·한계, 본문은 질문→자료→번호별 분석→해석→진단·민감도→결론 순서입니다. 학생용에는 해석 작성란, 교수자용에는 실행값을 반영한 예시 해석이 있습니다.

처음 한 번 install.packages(c("knitr", "rmarkdown"))로 패키지를 준비합니다. ZIP을 풀고 같은 폴더에서 `quarto render report-template.qmd --to html`을 실행하면 QMD 안의 번호별 R 청크를 실행해 표·그림을 생성합니다. 분석 코드와 학생 작성란은 QMD에서 수정합니다. 핵심 근거 선택·모형 선택·판단·해석은 학생이 작성하며 첫 페이지도 분석을 마친 뒤 직접 채웁니다. 별도 analysis.R 없이 실행할 수 있습니다. 캐시와 freeze를 사용하지 않습니다. 기본 R 중심의 분석으로 tidyverse와 broom은 필요하지 않습니다.

Word: `quarto render report-template.qmd --to docx`. PDF: `quarto render report-template.qmd --to pdf` (한국어 LaTeX 필요). styles.css·pagebreak.lua·reference.docx는 원본 템플릿 그대로 ZIP에 포함되어 있습니다. QMD 파일만 다운로드하면 이 보조파일과 데이터가 빠지므로 전체 ZIP을 사용하세요.

reference-output은 검산용입니다. 먼저 자신의 output을 만들고 숫자와 표본 수를 대조하세요. 그림의 글꼴·픽셀은 운영체제에 따라 달라질 수 있습니다.

## 기본 실습 1 · 관계도 두 개 그리기

조절은 광고→구매 선의 기울기에 연령이 관여하는 그림, 매개는 광고→태도→구매의 경로 그림으로 그립니다. 나이가 광고의 결과인지 생각해 보면 두 역할이 왜 다른지 알 수 있습니다.

## 기본 실습 2 · 조절모형과 중심화

age_c=age−평균연령을 만들고 ad_exposure*age_c를 적합합니다. 광고의 주계수는 평균연령에서의 기울기입니다. 20·40·60세의 기울기는 주계수+상호작용계수×(나이−평균나이)로 구합니다. 중심화가 관측치를 바꾸거나 상호작용을 새로 만드는 것은 아닙니다.

## 기본 실습 3 · 매개모형의 두 회귀

attitude~ad_exposure에서 a, purchase_amount~attitude+ad_exposure에서 b와 직접경로를 읽습니다. a×b가 간접경로입니다. 기본 실습은 완전관측 연속형 선형 경로를 이해하기 쉽게 lm 두 개로 계산하며, 교재 lavaan 전체 출력과 동일한 소프트웨어 분석이라고 부르지 않습니다.

## 기본 실습 4 · bootstrap으로 불확실성 확인

행을 복원추출해 두 회귀를 다시 적합하는 과정을 1,000회 반복합니다. 결과의 2.5%와 97.5% 지점을 구간으로 사용합니다. 행을 재추출해도 무작위 광고 실험으로 바뀌지 않습니다. 시간 순서, 혼란변수, 측정 품질이 없으면 인과 매개를 입증하지 못합니다.

## 기본 실습 5 · 장말 조절된 매개 연결

moderated-mediation.csv에서 태도식에 광고×나이를 넣습니다. 간접효과는 (a1+a3×나이)×b입니다. a1×b만 보고 모든 연령의 간접효과라고 말하면 안 됩니다. 출력표의 20·40·60세 값을 비교합니다.

## 멈추고 해석하기

방법 선택 이유, 결과의 조건·단위, 진단에 따른 판단 변경, 결론의 적용 범위와 한계를 자신의 말로 쓰세요.

## AI와 함께 확인하기

“광고·연령·태도·구매가 있다. 조절과 매개에 대한 질문을 구분하고, age 중심화 여부를 확인한 후 간접효과 식을 설명해줘. 계수 a1*b가 어느 나이에서의 값인지 꼭 써줘.” 복잡한 모형 이름보다 어떤 질문에 답하는지 먼저 검토합니다.

AI를 썼다면 질문, 제안받은 코드, 직접 확인한 결과, 수정한 해석을 따로 기록합니다. AI를 사용할 수 없는 날에도 제공된 코드와 설명으로 실습을 마칠 수 있습니다.

## 제출할 분석 기록

조절/매개 관계도, 세 연령의 기울기 표, 매개 bootstrap 구간, 조절된 간접경로 표, 인과 주장을 위해 더 필요한 조건을 제출합니다.

보고서 틀에 질문→자료→방법→근거→실행/보류 판단을 본인 말로 연결합니다. 공식 제출은 집현캠퍼스 안내를 따릅니다. 이 패키지에는 마감일이나 배점을 임의로 설정하지 않았습니다.

## 스스로 확인

중심화한 나이와 원래 나이를 식에 혼용하지 않았는가? 간접효과의 점추정과 유의성을 구별했는가?

## 막혔을 때

- 파일을 못 찾으면 getwd()와 list.files("data")를 확인합니다. ZIP 안에서 직접 실행하지 않습니다.
- 한글 열 이름이 다르면 원본 파일과 UTF-8 인코딩을 확인합니다. 자동으로 열 이름을 고쳐 다른 변수를 분석하지 않습니다.
- stopifnot 오류가 나면 행 수·열 이름·결측치부터 확인합니다. 검사를 지워서 통과시키지 않습니다.
- 수치가 다르면 data 파일, 선택한 그룹, 난수 시드, 패키지 버전을 먼저 대조합니다.
- Quarto는 선택한 폴더의 report-template.qmd를 렌더링합니다. HTML 생성과 R 분석 실행을 각각 확인합니다.
