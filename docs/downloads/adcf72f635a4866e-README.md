# 3장 LAB · 만족도가 다르다는 말, 세 가지 질문으로 나누기

A매장 만족도는 기준 4.0과 다른가요? A와 B는 서로 다른가요? 같은 직원의 교육 전후는 달라졌나요? 세 질문은 비슷해 보여도 기준과 관측 구조가 달라 같은 검정을 사용할 수 없습니다.

## 교재와 연결

[기술통계와 요약](https://kwangminpark.github.io/businessAnalytics/Chapter3.html) — 3.1~3.4 분포와 t-검정, 3.5 세 가지 t-test, 3.6~3.7 해석과 효과 크기

선수학습: 2장: 변수·표본·p값

권장 시간: 기본 100분 + 심화 30분 (수업 운영에 따라 조절)

## 이번 실습에서 배울 것

- 평균·중앙값·산포와 그림을 먼저 확인한다.
- 단일표본, 독립표본, 대응표본 t-검정을 자료 구조로 선택한다.
- 평균 차이와 신뢰구간을 p값과 함께 해석한다.

## 먼저 읽을 데이터

모두 data.zip의 교재 원본이며 교육용 가상자료입니다. ch3_data1.csv는 region·score 500행, ch3_data2.csv는 employee_id·group·score 1,000행(A/B 각 500), ch3_data3.csv는 employee_id·before·after 300행입니다. employee_id라는 열 이름만으로 실제 직원 조사라고 단정하지 않습니다. 대응자료 한 행의 before와 after가 같은 대상임을 전제로 하며 원본 ID 중복도 확인합니다. 지역 자료의 점수는 소수가 있는 수치형 교육자료이므로 정수형 리커트 단일 응답과 구분합니다.

## 준비와 실행

ZIP을 새 폴더에 풉니다. analysis.R와 data 폴더를 같은 위치에 두고, RStudio 프로젝트 또는 VS Code의 작업 폴더를 이 위치로 엽니다. 먼저 질문에 대한 예상을 쓰고 analysis.R의 번호별 구간을 차례로 실행하세요. 전체 재실행은 `Rscript --vanilla analysis.R`입니다. 원본 data를 덮어쓰지 않습니다. 결과는 output 폴더에 생성됩니다.

reference-output은 검산용입니다. 먼저 자신의 output을 만들고 숫자와 표본 수를 대조하세요. 그림의 글꼴·픽셀은 운영체제에 따라 달라질 수 있습니다.

## 기본 실습 1 · 검정 전에 요약과 그림

첫 파일로 지역별 n, 평균, 중앙값, 표준편차, IQR을 구합니다. 히스토그램 구간 수를 바꿨을 때 인상이 달라지는지도 봅니다. 자료를 두 번째 파일로 바꾸면 같은 표를 그대로 읽지 말고 변수명과 표본 수를 다시 확인합니다.

## 기본 실습 2 · 기준 하나와 비교

A만 선택한 뒤 t.test(a, mu=4)를 실행합니다. 귀무가설은 A의 모집단 평균이 4.0이라는 것입니다. 출력 신뢰구간은 A의 평균에 대한 구간이고, mean-differences.csv의 첫 행은 4를 뺀 차이의 구간입니다. 이 둘을 구별해 기록합니다.

## 기본 실습 3 · 서로 다른 두 집단 비교

t.test(a,b)는 기본적으로 Welch 검정입니다. A−B의 방향을 먼저 써 두고 차이와 구간을 읽습니다. 교재의 var.test 출력 p≈0.000196은 0.05보다 작습니다. 그 아래 “유의하지 않다”는 설명과 맞지 않으므로 실제 출력에 따라 판단합니다. F검정 통과 여부만으로 Welch를 사용할지 결정할 필요는 없습니다.

## 기본 실습 4 · 같은 대상의 변화 비교

paired=TRUE로 after−before를 분석합니다. 원문은 before−after이므로 t값과 차이의 부호가 반대입니다. 부호가 다르다고 계산 오류가 아닙니다. 사람마다 두 값이 짝지어졌는지 확인하고, 교육이 원인이라는 주장에 통제집단이나 시기 효과 점검이 추가로 필요한 이유를 적습니다.

## 멈추고 해석하기

원본 실행에서 A−4는 약 0.119점(95% 구간 0.070~0.168), A−B는 약 0.334점(0.258~0.409), 교육 후−전은 약 0.407점(0.374~0.441)입니다. 작게 표시되는 p값이 0인 것은 아닙니다. “통계적으로 차이가 있다” 다음에는 그 차이가 비용을 들여 대응할 만큼 큰지 별도 기준이 필요합니다. 95% 신뢰구간은 같은 절차를 반복할 때 구간이 모평균 차이를 포함하는 장기 비율을 뜻합니다.

## AI와 함께 확인하기

“A−B 평균차이와 95% 신뢰구간을 내가 계산했다. 검정은 Welch이고, 가상자료다. 이 결과로 말할 수 있는 문장과 말할 수 없는 문장을 하나씩 써줘. 신뢰구간의 대상과 차이의 방향을 확인해줘.” 교육 전후 자료는 ID와 paired 옵션을 따로 설명하세요.

AI를 썼다면 질문, 제안받은 코드, 직접 확인한 결과, 수정한 해석을 따로 기록합니다. AI를 사용할 수 없는 날에도 제공된 코드와 설명으로 실습을 마칠 수 있습니다.

## 막혔을 때

- 파일을 못 찾으면 getwd()와 list.files("data")를 확인합니다. ZIP 안에서 직접 실행하지 않습니다.
- 한글 열 이름이 다르면 원본 파일과 UTF-8 인코딩을 확인합니다. 자동으로 열 이름을 고쳐 다른 변수를 분석하지 않습니다.
- stopifnot 오류가 나면 행 수·열 이름·결측치부터 확인합니다. 검사를 지워서 통과시키지 않습니다.
- 수치가 다르면 data 파일, 선택한 그룹, 난수 시드, 패키지 버전을 먼저 대조합니다.
- Quarto는 선택한 폴더의 report-template.qmd를 렌더링합니다. HTML 생성과 R 분석 실행을 각각 확인합니다.
