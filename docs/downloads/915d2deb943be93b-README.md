# LAB-03 · 식사금액이 클수록 팁도 클까?

식사금액과 팁의 산점도를 먼저 보고 관계의 방향·퍼짐·영향력이 큰 관측치를 예상한다. 단순회귀와 인원수·요일을 포함한 회귀를 비교하고, 조건부 연관성을 인과효과와 구분한다.

## 데이터와 출처

원전: 박광민, 『비즈니스 애널리틱스』 6장 6.1 및 6.10. https://kwangminpark.github.io/businessAnalytics/Chapter6.html

원전은 `reshape2` 패키지의 `tips`를 사용한다. 이 패키지의 `data/tips.csv`는 CRAN 소스 미러 `cran/reshape2`의 `data/tips.rda`를 실제 R에서 읽어 CSV로 내보낸 것이다. 데이터에 새로운 행이나 값을 추가하지 않았다. 정확한 파일 해시는 `provenance.json`에 기록한다. 오프라인 실습에서는 이 CSV를 사용하므로 reshape2 설치가 필요 없다.

244행·7열이며 결측치는 없다. 한 행은 식사 계산서 한 건이다. `total_bill`과 `tip`은 미국 달러, `size`는 동석 인원수다. `day`는 Thur/Fri/Sat/Sun, `time`은 Lunch/Dinner, `sex`와 `smoker`는 원본의 범주 변수다. 금액을 원화나 천원 단위로 바꾸어 읽지 않는다. 국내 외식업 전체의 대표 표본이라고 간주하지 않는다.

## 실행하기

패키지를 새 폴더에 풀어 RStudio 프로젝트로 연다. `analysis.R`를 Source하거나 이 폴더에서 `Rscript --vanilla analysis.R`를 실행한다. 추가 패키지는 필요 없다. 생성된 회귀계수 CSV, 산점도, 네 가지 진단 그림을 `reference-output`과 비교한다.

단순모형: `tip ~ total_bill`.

조건부모형: `tip ~ total_bill + size + day`. 요일 기준범주는 Sun으로 명시한다. 코드에서 factor 순서를 고정하므로 환경의 기본 정렬 순서에 의존하지 않는다.

## 기준 출력과 해석

조건부모형에서 `total_bill` 계수는 약 **0.092994**이며 고전적 95% 신뢰구간은 **[0.074793, 0.111195]**다. 인원수와 요일이 같은 조건에서, 식사금액 1달러 차이는 평균 팁 약 0.093달러 차이와 연관된다. 10달러 차이에 대해서는 약 0.930달러다. 이는 가격을 10달러 올리면 팁이 그만큼 증가한다는 실험적 인과효과가 아니다.

인원수 계수는 약 0.187132다. 인원수와 식사금액은 연관될 수 있으므로 단순모형과 조건부모형의 계수를 혼동하지 않는다. 요일 계수가 유의하지 않다고 요일 효과가 정확히 0임을 입증한 것은 아니다.

잔차-적합값 그림에서 퍼짐을, Q-Q 그림에서 꼬리 형태를, 잔차-레버리지 그림에서 영향력을 살핀다. 가장 큰 Cook 거리는 약 0.238이다. 자동 삭제 기준으로 쓰지 말고 원자료와 민감도 분석의 단서로 사용한다. `se-comparison.csv`의 HC3 표준오차는 비등분산에 대한 민감도 비교이며 독립성·표본 대표성까지 보장하지 않는다.

## 바꿔 해보기

1. 인원수 2명·일요일·식사금액 20달러와 30달러의 예측값을 구해 계수의 10배 차이와 비교한다.
2. Cook 거리가 가장 큰 한 건을 제외한 모형을 별도로 적합하고 `total_bill` 계수 변화량을 보고한다. 원본 결과도 함께 남긴다.
3. 원본 범위 밖 100달러 계산서에 대한 예측이 왜 외삽인지 설명한다. 설명력과 새 데이터 예측 성능이 같은 개념인지 논의한다.

## 막힐 때와 결과물

`object 'total_bill' not found`는 파일·열 이름을 먼저 확인한다. 요일 계수가 다르면 기준범주와 factor 순서를 확인한다. `could not find function` 오류가 나면 스크립트 전체를 처음부터 Source했는지 확인한다. 값이 다르면 CSV 해시, 행 수, 제외 관측, 모형식을 순서대로 비교한다.
