# LAB-02 · 집단별 매출 차이, 90행을 독립 표본으로 봐도 될까?

세 브랜드 표시의 하루 매출을 비교한다. 계산 전에 “30일씩 3집단이면 독립적인 매장 90개를 관찰한 것인가?”에 답한다. 평균 차이 계산과 일반화 가능한 경영 판단을 구분하는 것이 목표다.

## 데이터와 출처

원전: 박광민, 『비즈니스 애널리틱스』 4장 4.4. https://kwangminpark.github.io/businessAnalytics/Chapter4.html

`data/ch4_data.csv`는 원전 저장소 commit `c7741bed344d0f6620f2fa65de6b5256f903011a`의 교육용 자료다. 원전은 동일 지역 경쟁 매장을 설정한 수업 상황을 설명한다. 실측 여부·표집 과정·생성 시드는 확인되지 않았으므로 실제 브랜드 매출 실적이라고 주장하지 않는다. 이 패키지에서 새 관측값이나 날짜를 만들지 않았다.

한 행은 브랜드 표시 하나의 하루다. 원본에 있는 2025년 6월 관측 날짜는 데이터 변수이며 **2026년도 2학기 수업 일정이 아니다**. 브랜드별 30일, 전체 90행이다. `날짜`와 `브랜드`의 조합은 중복되지 않으며 결측치는 없다. 매장 ID는 없다. 같은 매장의 반복 측정 여부와 모집단을 확정할 수 없다.

변수: `날짜`(관측 일자), `브랜드`(교재의 집단 표시), `일매출`(원), `방문객수`(명), `구매고객수`(명), `평균체류시간_분`(분). 코드는 원본을 읽은 뒤 열 이름만 영문으로 바꾼다. 그림의 영문 브랜드 표시는 원본 범주에 대응한다.

## 실행하기

새 폴더에 패키지를 풀고 RStudio 프로젝트로 연 뒤 `analysis.R`를 Source한다. 또는 이 폴더에서 `Rscript --vanilla analysis.R`를 실행한다. 추가 R 패키지는 필요 없다. `output/summary.csv`, `tukey.csv`, `model-metrics.csv`, `sales-comparison.png`, `diagnostics.png`가 생성된다. 제공된 `reference-output`과 비교한다.

## 기준 출력 읽기

| 교재 표시 | 일수 | 평균 일매출(원) | 표준편차(원) |
|---|---:|---:|---:|
| Starbucks | 30 | 1,677,475.30 | 122,632.85 |
| Compose | 30 | 909,886.93 | 77,857.45 |
| Mega | 30 | 1,186,152.93 | 116,788.48 |

일원분산분석과 Tukey 사후 비교는 독립성 등 모형 조건을 가정한 교육용 계산이다. 상자그림, 잔차-적합값 그림, Q-Q 그림과 집단별 분산을 함께 확인한다. Fligner 검정이 유의하지 않더라도 독립성이 입증되지는 않는다. Welch 분석은 분산이 같은지에 대한 가정을 완화하지만 반복 관측 문제를 해결하지 않는다.

`sales ~ factor(date) + brand`는 같은 날짜의 공통 변동을 통제하는 보조 비교다. 이 모형 역시 매장 내 시계열 상관을 자동으로 해결하지 않는다. 예를 들어 Mega 표시의 일매출 지연 1 상관은 약 0.516으로 계산된다. 짧은 시계열의 표본 상관만으로 생성 과정을 확정할 수 없지만, 행 간 독립성을 당연시해서는 안 된다는 점을 확인할 수 있다.

적절한 결론: “제공된 교재 데이터에서는 세 표시의 평균 일매출이 다르다. 모형의 검정 결과는 가정에 의존하며 실제 브랜드 전체로 일반화할 근거가 없다.” 부적절한 결론: “이 결과로 특정 브랜드에 투자해야 한다.” 실제 의사결정에는 매장 수, 규모·입지·영업시간, 표집 설계, 비용과 반복 관측 처리가 추가로 필요하다.

## 바꿔 해보기

1. `일매출 / 구매고객수`를 만들어 매출 순위와 구매 고객당 금액 순위를 비교한다. 분모가 0인지 먼저 검사한다.
2. 일원모형과 날짜 블록 모형의 결과를 비교하되 “문제가 해결됐다”라고 단정하지 않는다.
3. 실제 브랜드 수준 비교를 설계한다면 필요한 매장 ID·반복 기간·입지 변수를 목록으로 작성한다.

## 막힐 때와 결과물
