기본 실습 1 · 관계도 두 개 그리기

조절은 광고→구매 선의 기울기에 연령이 관여하는 그림, 매개는 광고→태도→구매의 경로 그림으로 그립니다. 나이가 광고의 결과인지 생각해 보면 두 역할이 왜 다른지 알 수 있습니다.

기본 실습 2 · 조절모형과 중심화

age_c=age−평균연령을 만들고 ad_exposure*age_c를 적합합니다. 광고의 주계수는 평균연령에서의 기울기입니다. 20·40·60세의 기울기는 주계수+상호작용계수×(나이−평균나이)로 구합니다. 중심화가 관측치를 바꾸거나 상호작용을 새로 만드는 것은 아닙니다.

기본 실습 3 · 매개모형의 두 회귀

attitude~ad_exposure에서 a, purchase_amount~attitude+ad_exposure에서 b와 직접경로를 읽습니다. a×b가 간접경로입니다. 기본 실습은 완전관측 연속형 선형 경로를 이해하기 쉽게 lm 두 개로 계산하며, 교재 lavaan 전체 출력과 동일한 소프트웨어 분석이라고 부르지 않습니다.

기본 실습 4 · bootstrap으로 불확실성 확인

행을 복원추출해 두 회귀를 다시 적합하는 과정을 1,000회 반복합니다. 결과의 2.5%와 97.5% 지점을 구간으로 사용합니다. 행을 재추출해도 무작위 광고 실험으로 바뀌지 않습니다. 시간 순서, 혼란변수, 측정 품질이 없으면 인과 매개를 입증하지 못합니다.

기본 실습 5 · 장말 조절된 매개 연결

moderated-mediation.csv에서 태도식에 광고×나이를 넣습니다. 간접효과는 (a1+a3×나이)×b입니다. a1×b만 보고 모든 연령의 간접효과라고 말하면 안 됩니다. 출력표의 20·40·60세 값을 비교합니다.

## 1. 7.2: 연령에 따라 광고노출의 기울기가 달라지는가?

```{r}

# 1. 7.2: 연령에 따라 광고노출의 기울기가 달라지는가?
d <- read_data("moderation.csv"); stopifnot(nrow(d)==300,!anyNA(d))
d$age_c <- d$age-mean(d$age)
m <- lm(purchase_amount~ad_exposure*age_c,data=d)
export(coef_table(m),"moderation-coefficients")
ages <- c(20,40,60)
slopes <- coef(m)["ad_exposure"]+coef(m)["ad_exposure:age_c"]*(ages-mean(d$age))
export(data.frame(age=ages,slope=as.numeric(slopes)),"conditional-slopes")
picture("conditional-slopes")
plot(d$ad_exposure,d$purchase_amount,pch=16,col="#236b6640",xlab="Ad exposures",ylab="Purchase (teaching units)")
for(i in seq_along(ages)) { nd <- data.frame(ad_exposure=0:12,age_c=ages[i]-mean(d$age)); lines(nd$ad_exposure,predict(m,nd),col=i+1,lwd=2) }
```

## 2. 7.3: 광고 -> 태도 -> 구매의 간접경로. 행을 재추출하는 bootstrap.

```{r}
#| label: analysis-2
# 2. 7.3: 광고 -> 태도 -> 구매의 간접경로. 행을 재추출하는 bootstrap.
e <- read_data("mediation.csv")
paths <- function(x) { a <- coef(lm(attitude~ad_exposure,x))["ad_exposure"]; f <- lm(purchase_amount~attitude+ad_exposure,x); b <- coef(f)["attitude"]; cp <- coef(f)["ad_exposure"]; c(a=unname(a),b=unname(b),direct=unname(cp),indirect=unname(a*b),total=unname(cp+a*b)) }
set.seed(20261002); draws <- replicate(1000,paths(e[sample(nrow(e),replace=TRUE),]))
ci <- t(apply(draws,1,quantile,c(.025,.975)))
export(data.frame(path=names(paths(e)),estimate=paths(e),low=ci[,1],high=ci[,2]),"mediation-bootstrap")
```

```{r}
# 3. 7.4.6: a1*b는 age=0에서만 간접효과입니다. 나이를 대입해야 합니다.
```

# Appendix B. 실행 환경 {.unnumbered}

처음 한 번 `install.packages(c("knitr", "rmarkdown"))`로 패키지를 준비합니다. ZIP을 풀고 QMD·data·styles.css·pagebreak.lua·reference.docx를 같은 폴더에 둡니다. 별도 analysis.R 없이 실행합니다. 캐시와 freeze는 사용하지 않습니다.

```bash
quarto render report-template.qmd --to html
quarto render report-template.qmd --to docx
quarto render report-template.qmd --to pdf
```

PDF에는 한국어 LaTeX 환경이 필요합니다. 공식 제출은 집현캠퍼스 안내를 따릅니다.
