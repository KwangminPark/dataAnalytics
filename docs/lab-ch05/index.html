기본 실습 1 · 2×2 표부터 그리기

요일을 열, 매장유형을 행으로 놓고 각 셀에 n·평균·표준편차를 적습니다. 주말 증가가 어느 유형에서 더 큰지 계산 전에 예상합니다. 전체 주말 평균 하나로 두 매장을 설명할 수 있을지 토론합니다.

기본 실습 2 · 별표(*)가 포함하는 항 이해

sales~type*day는 type, day, type:day를 함께 넣습니다. 상호작용 항은 주말 차이가 매장유형에 따라 달라지는지를 확인합니다. 상호작용 그림의 선이 비평행하다는 시각적 단서와 p값·차이 크기를 함께 봅니다.

기본 실습 3 · 주효과가 약한 두 번째 사례

5.6의 고객당매출을 시간대×매장유형으로 분석합니다. 점심/저녁 전체 평균만 본 결론과 네 셀을 본 결론을 비교합니다. 직영점은 저녁, 가맹점은 점심의 관측 평균이 높은 구조를 확인하되 회식 수요 등 자료에 없는 이유는 가설로 표시합니다.

기본 실습 4 · 모형 순서와 해석 범위 확인

첫 자료에서 두 주효과의 순서를 바꿔 본 출력도 읽습니다. 셀 수가 다르면 기본 aov의 순차 제곱합이 순서에 영향을 받을 수 있습니다. 이번 질문은 상호작용과 셀별 차이에 초점을 둡니다. 두 모형 비교 출력은 상호작용을 추가했을 때의 변화를 보여줍니다.

```{r}
#| label: analysis-1
# 1. 5.5: 두 요인의 조합별 표본 수와 평균부터 확인
raw <- read_data("ch5_data2.csv")
d <- data.frame(type=factor(raw$매장유형,levels=c("가맹점","직영점")),day=factor(raw$요일,levels=c("평일","주말")),sales=raw$일매출)
stopifnot(nrow(d)==520,!anyNA(d))
print(table(d$type,d$day))
z <- summary_by(d$sales,interaction(d$type,d$day))
export(data.frame(cell=rownames(z),z,row.names=NULL),"day-type-means")
full <- aov(sales~type*day,data=d)
print(summary(full))
# 불균형 자료의 순차 제곱합은 입력 순서에 영향을 받습니다.
print(summary(aov(sales~day*type,data=d)))
print(anova(lm(sales~type+day,data=d),lm(sales~type*day,data=d)))
```

# Appendix B. 실행 환경 {.unnumbered}

처음 한 번 `install.packages(c("knitr", "rmarkdown"))`로 패키지를 준비합니다. ZIP을 풀고 QMD·data·styles.css·pagebreak.lua·reference.docx를 같은 폴더에 둡니다. 별도 analysis.R 없이 실행합니다. 캐시와 freeze는 사용하지 않습니다.

```bash
quarto render report-template.qmd --to html
quarto render report-template.qmd --to docx
quarto render report-template.qmd --to pdf
```
