먼저 판단할 질문

팁이 큰 테이블은 식사금액이 컸기 때문일까요, 인원이 많았기 때문일까요? “식사금액이 1달러 늘면”이라는 문장에 어떤 조건이 붙는지, 예측을 얼마나 믿을 수 있는지 배웁니다.

교재에서 실습으로

교재 6장 회귀분석: 통계의 꽃 6.1~6.9 계수·더미·적합도·진단, 6.10 tips 종합실습과 이분산 과제 선수학습: 3~5장: 평균 비교와 가정 권장 시간: 기본 110분 + 심화 30분 1. 단순 연관성과 다른 변수를 고려한 회귀계수를 구별한다. 2. 기준범주·수정 R제곱·잔차 진단을 읽는다. 3. 이분산이 있을 때 계수와 표준오차의 역할을 구분한다.

자료와 한 행의 의미

tips.csv는 교재 6.10의 reshape2::tips 244건을 고정된 원본에서 CSV로 내보낸 자료입니다. R 기본 datasets에 포함된 자료는 아닙니다. 한 행은 식사 계산서 기록이며 total_bill·tip은 달러, size는 동석 인원, day는 요일, time은 점심/저녁, sex·smoker는 기록된 범주입니다. 동일한 상황/관측자의 기록에 따른 한계가 있어 모든 국가·식당의 팁 행동으로 일반화하지 않습니다. 성별 같은 속성의 계수를 사람의 본질이나 서비스 배분 근거로 해석하지 않습니다.

기본 실습 1 · 질문과 단위를 먼저 기록

산점도와 요약을 보고 단순모형 tip~total_bill을 생각합니다. 이번 종속변수는 팁 비율이 아니라 팁 금액입니다. tips를 읽은 뒤 day의 기준을 Sun으로 지정했는지 확인합니다.

기본 실습 2 · 교재 모형의 계수 읽기

tip~total_bill+size+day의 계수표를 읽습니다. total_bill 계수는 인원수와 요일이 같다고 놓았을 때의 조건부 연관성입니다. daySat 계수는 같은 금액·인원의 Sun과 비교한 차이입니다. 절편은 자료에서 현실적인 조건인지 따져 봅니다.

기본 실습 3 · 변수를 더 넣으면 무조건 좋아질까

sex+smoker+time을 추가한 모형의 R제곱과 수정 R제곱을 비교합니다. R제곱이 조금 커졌다는 이유만으로 좋은 모형이라고 결론 내리지 않습니다. 더미열 VIF도 확인하되 개별 더미의 지표이며 요일 전체의 일반화 VIF와 같지 않음을 구별합니다.

기본 실습 4 · 장말 과제: 이분산에 대응

잔차 그림에서 예측값에 따라 흩어짐이 달라지는지 봅니다. hc3.csv에서 보통 표준오차와 HC3 표준오차를 비교합니다. HC3는 오차 크기가 일정하지 않을 때 추론의 민감도를 살피는 방법입니다. 계수를 바꾸거나 빠진 변수, 비선형 관계, 인과 문제를 해결해 주는 버튼은 아닙니다.

## 5. 단순회귀와 인원수·요일을 고려한 모형

```{r}
#| label: regression-models
# 5. 모형식은 이곳에서 수정합니다. Sun은 요일의 기준범주입니다.
simple <- lm(tip ~ total_bill, data = d)
model <- lm(tip ~ total_bill + size + day, data = d)
show_table(coef_table(simple), "단순모형 계수와 95% 신뢰구간")
coefficients <- export(coef_table(model), "coefficients")
show_table(coefficients, "인원수·요일을 고려한 모형 계수")
bill <- coefficients[coefficients$term == "total_bill", ]
size_effect <- coefficients[coefficients$term == "size", ]
```

열 `estimate`는 계수, `se`는 보통 표준오차, `p`는 양측 p값,
`low`와 `high`는 보통 표준오차에 따른 95% 신뢰구간입니다.

## 8. HC3 표준오차 비교

```{r}
#| label: hc3-comparison
# 8. 계수는 유지하고 표준오차와 구간의 민감도를 비교합니다.
X <- model.matrix(model)
bread <- solve(crossprod(X))
weights <- residuals(model)^2 / (1 - hatvalues(model))^2
hc3 <- bread %*% crossprod(X, X * weights) %*% bread
se <- sqrt(diag(hc3))
tcrit <- qt(.975, df.residual(model))
hc3_results <- export(data.frame(
  term = names(coef(model)), estimate = coef(model),
  usual_se = coef(summary(model))[, 2], hc3_se = se,
  hc3_low = coef(model) - tcrit * se, hc3_high = coef(model) + tcrit * se
), "hc3")
show_table(hc3_results, "보통 표준오차와 HC3 표준오차 비교")
```

HC3 구간은 잔차 자유도의 t 임계값을 사용하는 이 실습의 계산 방식입니다.
