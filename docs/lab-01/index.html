분석 질문과 먼저 생각하기

네 지역의 만족도 평균만 보고 개선 순서를 정할 수 있을까? 먼저 평균 순위를 예상하고, 표본 수·중앙값·산포·상한값 집중도를 확인한 뒤 자신의 판단을 수정한다.

데이터 이해

원전: 박광민, 『비즈니스 애널리틱스』 3장 3.2.5. https://kwangminpark.github.io/businessAnalytics/Chapter3.html `data/ch3_data1.csv`는 원전 저장소 commit `c7741bed344d0f6620f2fa65de6b5256f903011a`에서 확보한 **가상의 교육용 자료**다. 실제 지역 고객 만족도 조사라고 해석하지 않는다. 원전 CSV의 생성 시드는 확인되지 않았다. 이 패키지에서 데이터를 새로 합성하거나 값을 보정하지 않았다. 한 행은 지역 표시와 점수 한 건이다. `region`은 Seoul/Gyeonggi/Busan/Daejeon, `score`는 1~5 범위의 연속 소수 점수다. 500행이며 결측치는 없다. 응답자 ID·조사 날짜·추출 방법이 없어 같은 사람의 반복 응답 여부를 검증할 수 없다. 정확히 같은 행이 36개 있지만 지역과 점수가 같다는 이유만으로 삭제하면 안 된다.

내 PC에서 실행하기

1. ZIP을 새 폴더에 풀고 `analysis.R`와 `data` 폴더가 나란히 있는지 확인한다. 2. RStudio에서 이 폴더를 프로젝트로 연다. `analysis.R`를 열고 Source를 실행한다. 터미널에서는 `Rscript --vanilla analysis.R`로 실행할 수 있다. 3. `output/summary.csv`, `distributions.png`, `results.txt`를 연다. 추가 R 패키지는 필요 없다. 4. 제공된 `reference-output`과 자신의 `output`을 비교한다. 그림의 점 위치는 시드 20260915로 고정했다. 운영체제별 글꼴·PNG 압축 차이는 가능하므로 숫자를 우선 비교한다.

따라 하기

# LAB-01. Original textbook's fictional teaching data; not observed store results.
# Run in this package directory: Rscript --vanilla analysis.R
options(digits = 7)
d <- read.csv("data/ch3_data1.csv", fileEncoding = "UTF-8", stringsAsFactors = FALSE)
stopifnot(identical(names(d), c("region", "score")), nrow(d) == 500,
          !anyNA(d), all(d$score >= 1 & d$score <= 5))
d$region <- factor(d$region, levels = c("Seoul", "Gyeonggi", "Busan", "Daejeon"))
stopifnot(!anyNA(d$region))
dir.create("output", showWarnings = FALSE)
summary_table <- do.call(rbind, lapply(levels(d$region), function(region) {
  x <- d$score[d$region == region]
  data.frame(region = region, n = length(x), mean = mean(x), median = median(x),
             sd = sd(x), q1 = unname(quantile(x, .25)), q3 = unname(quantile(x, .75)),
             min = min(x), max = max(x), share_at_5 = mean(x == 5))
}))
write.csv(summary_table, "output/summary.csv", row.names = FALSE)
png("output/distributions.png", width = 1400, height = 650, res = 140)
par(mfrow = c(1, 2), mar = c(5, 4, 3, 1))
boxplot(score ~ region, d, ylim = c(1, 5), col = c("#8bb89c", "#e1ca83", "#98b7c6", "#c8a8b3"),
        xlab = "Region", ylab = "Satisfaction score", main = "Distribution, not just a mean")
set.seed(20260915)
stripchart(score ~ region, d, vertical = TRUE, method = "jitter", add = TRUE,
           pch = 16, cex = .3, col = "#243b3250")
plot(ecdf(d$score[d$region == levels(d$region)[1]]), xlim = c(1, 5),
     main = "Empirical cumulative distribution", xlab = "Score", ylab = "Share at or below score",
     col = "#24654e", verticals = TRUE, do.points = FALSE)
colors <- c("#24654e", "#946300", "#2c6985", "#954574")
for (i in 2:4) lines(ecdf(d$score[d$region == levels(d$region)[i]]), col = colors[i], do.points = FALSE)
legend("topleft", levels(d$region), col = colors, lty = 1, bty = "n", cex = .8)
dev.off()
capture.output({cat("LAB-01: textbook fictional teaching data\n"); print(summary_table);
  cat("\nMissing cells:", sum(is.na(d)), "\nExact duplicate rows:", sum(duplicated(d)),
      "\nDuplicate scores are not duplicate people: there is no respondent identifier.\n")},
  file = "output/results.txt")
capture.output(sessionInfo(), file = "output/session-info.txt")
cat(readLines("output/results.txt"), sep = "\n")

결과 해석

| 지역 | n | 평균 | 중앙값 | 표준편차 | |---|---:|---:|---:|---:| | Seoul | 154 | 3.91694 | 3.89496 | 0.66682 | | Gyeonggi | 131 | 3.96120 | 3.91982 | 0.67167 | | Busan | 118 | 4.02190 | 4.07201 | 0.56519 | | Daejeon | 97 | 4.02552 | 4.10011 | 0.69298 | 평균 차이는 작고 분포가 겹친다. Daejeon의 평균이 가장 높지만 표준편차도 가장 크다. Busan과 Daejeon의 평균만으로 두 집단의 일관성을 설명할 수 없다. Gyeonggi의 5점 비율은 약 13.74%로, 상한값 집중도도 따로 확인할 만하다. 적절한 표현: “이 교육용 데이터에서 Busan의 점수 산포가 Daejeon보다 작다.” 과장된 표현: “부산 매장이 실제로 더 좋은 서비스를 제공한다.” 후자는 실제 조사·표본 설계·서비스 측정 정보가 없어 지지되지 않는다. 상한이 있는 점수에 정규분포 범위를 무조건 적용하지 않는다.

바꿔 해보기

`score >= 4`의 지역별 비율을 계산하고 평균 순위와 비교한다. 기준을 4.5로 바꾸면 순위가 유지되는가? 두 기준의 분자·분모를 함께 기록한다. 중복 행을 삭제하지 않은 이유를 설명한다. 평균과 중앙값 중 어느 하나를 정답으로 고르기보다 질문에 따라 무엇을 읽을지 서술한다.

막힐 때

오류와 확인 순서 펼치기

- `cannot open file`: `getwd()`와 `list.files("data")`를 확인한다. ZIP 안에서 바로 실행하지 않는다. - `object 'score' not found`: `names(d)`를 확인한다. 다른 장의 CSV를 넣었는지 확인한다. - `stopifnot` 실패: 원본 행 수·열 이름·결측치·범위를 확인한다. 검사를 지워서 통과시키지 않는다. - 결과가 다름: 파일 버전, 그룹별 n, 필터 유무, 결측치 처리를 순서대로 비교한다.
