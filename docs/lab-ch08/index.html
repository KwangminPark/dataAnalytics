기본 실습 1 · 분석 전에 척도 감사

scale-audit.csv의 범위·평균·표준편차를 확인해 본문 설명과 실제 값의 차이를 적습니다. ID 같은 식별자가 포함되지 않았는지도 봅니다. 상관행렬에서 함께 움직이는 문항을 찾되 응답자가 같은 이유로 답했다고 단정하지 않습니다.

기본 실습 2 · 표준화 PCA 실행

prcomp(x, center=TRUE, scale.=TRUE)를 실행합니다. sdev²가 고유값이며 전체 고유값 합으로 나누면 분산 비율입니다. 고유값·비율·누적 비율을 직접 연결해 2개와 4개 축을 남길 때의 차이를 씁니다. 고유값 1은 표준화 기준의 참고 규칙이지 유일한 정답이 아닙니다.

기본 실습 3 · 축에 이름 붙이기

PC2에서 음식 문항 Q4~6과 환경 문항 Q7~9가 반대 부호임을 확인합니다. “음식 품질이 좋으면 환경이 나빠진다”는 인과관계가 아니라 이 표본에서 축이 표현하는 대비입니다. rotation은 축의 가중치이고 변수와 주성분의 상관은 rotation×sdev임을 두 출력으로 비교합니다.

기본 실습 4 · KMO와 Bartlett 읽기

KMO와 Bartlett은 문항 간 상관구조를 점검하는 참고자료입니다. 유의한 Bartlett이 네 개 축의 경영적 의미까지 검증하지는 않습니다. PCA의 목적은 분산을 보존하는 압축이고, 보이지 않는 공통 원인을 탐색하는 요인분석은 9장에서 구별해 다룹니다.

## 1. 교재 8장 원본 ch7_data1.csv: 이름은 ch7이지만 PCA 자료입니다.

```{r}
#| label: analysis-1
# 1. 교재 8장 원본 ch7_data1.csv: 이름은 ch7이지만 PCA 자료입니다.
x <- read_data("ch7_data1.csv")
stopifnot(nrow(x)==300,identical(names(x),paste0("Q",1:12)),!anyNA(x),all(sapply(x,sd)>0))
export(data.frame(item=names(x),min=sapply(x,min),max=sapply(x,max),mean=sapply(x,mean),sd=sapply(x,sd)),"scale-audit")
# 실제 값은 음수도 있는 연속 수치입니다. 1~5 응답으로 간주하여 자르지 않습니다.
R <- cor(x)
export(data.frame(item=names(x),R),"correlations")
p <- prcomp(x,center=TRUE,scale.=TRUE)
v <- p$sdev^2
export(data.frame(PC=paste0("PC",1:12),eigenvalue=v,proportion=v/sum(v),cumulative=cumsum(v/sum(v))),"variance")
# rotation은 축의 가중치, 변수-PC 상관은 가중치 * 해당 PC의 SD입니다.
export(data.frame(item=names(x),p$rotation[,1:4]),"rotation")
export(data.frame(item=names(x),sweep(p$rotation[,1:4],2,p$sdev[1:4],"*")),"variable-pc-correlations")
if(!requireNamespace("psych",quietly=TRUE)) stop('install.packages("psych")가 필요합니다.')
print(psych::KMO(x)); print(psych::cortest.bartlett(R,n=nrow(x)))
picture("pca",1200,800); par(mfrow=c(2,2))
image(1:12,1:12,R,axes=FALSE,xlab="Item",ylab="Item",main="Correlation matrix"); axis(1,1:12,names(x)); axis(2,1:12,names(x))
plot(1:12,v,type="b",xlab="PC",ylab="Eigenvalue"); abline(h=1,lty=2)
plot(1:12,cumsum(v/sum(v)),type="b",xlab="PCs retained",ylab="Cumulative variance",ylim=c(0,1))
barplot(p$rotation[,2],names.arg=names(x),las=2,ylab="PC2 weight")
dev.off()
```
